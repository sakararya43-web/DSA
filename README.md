# 🧠 My Learning Philosophy

> **Don't memorize solutions. Understand the pattern.**

For every problem, I try to understand:

* Why does the approach work?
* What is the underlying pattern?
* Can I derive the solution myself?
* Can I optimize the brute-force solution?
* What are the edge cases?
* What are the time and space complexities?

# 📚 Useful Complexity Cheat Sheet

| Data Structure / Algorithm |       Average Time |
| -------------------------- | -----------------: |
| Array Access               |             `O(1)` |
| HashMap Search             |             `O(1)` |
| HashSet Search             |             `O(1)` |
| Binary Search              |         `O(log n)` |
| Merge Sort                 |       `O(n log n)` |
| Quick Sort                 |       `O(n log n)` |
| Heap Insert                |         `O(log n)` |
| Heap Remove                |         `O(log n)` |
| BFS                        |         `O(V + E)` |
| DFS                        |         `O(V + E)` |
| Dijkstra                   | `O((V + E) log V)` |
| Floyd-Warshall             |            `O(V³)` |
| Kruskal                    |       `O(E log E)` |
| Prim                       |       `O(E log V)` |
